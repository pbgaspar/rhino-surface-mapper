binary distribution.

- Apache-2.0.txt was downloaded unchanged from
  https://www.apache.org/licenses/LICENSE-2.0.txt
- LGPL-3.0.txt was downloaded unchanged from
  https://www.gnu.org/licenses/lgpl-3.0.txt
- Python-3.13.15.txt was downloaded unchanged from the CPython v3.13.15 tag:
  https://github.com/python/cpython/blob/v3.13.15/LICENSE
- OpenSSL-3.0.21.txt was downloaded unchanged from the OpenSSL 3.0.21 tag:
  https://github.com/openssl/openssl/blob/openssl-3.0.21/LICENSE.txt
- Qt-6.11.2-Third-Party-Notices.html consolidates the complete attribution
  articles from the official Qt 6.11.2 documentation at
  https://doc.qt.io/qt-6/. It includes only the pages mapped in
  THIRD_PARTY_NOTICES.txt to the validated bundle and identifies each original
  page and official URL.

The root LICENSE file contains the unmodified GNU GPL version 3 text applying
to Rhino Surface Mapper and the GPLv3 open-source distribution route.
